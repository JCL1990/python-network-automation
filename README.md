# Python Network Automation

This repository documents my progress learning Python and network automation.

## Project 1: Device Status Checker

A beginner Python project that checks the status of network devices using sample device inventory data.

### What it does
- Stores network devices in a list of dictionaries.
- Uses a function to check each device.
- Identifies devices that are offline.
- Identifies devices assigned to VLAN 30 when online.
- Counts the number of offline devices.

### Python concepts practiced
- Variables and data types
- Lists and dictionaries
- For loops
- Functions and return values
- If / elif / else statements
- Boolean logic
- Counters

### Current limitations
This project uses simulated device data. It does not connect to physical network equipment or modify network configurations.
